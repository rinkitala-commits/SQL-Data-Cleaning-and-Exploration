# SQL Data Cleaning and Exploration

A SQL-based data cleaning and exploratory data analysis project using a layoffs dataset.

The project focuses on transforming raw data into a cleaner and more analysis-ready dataset using SQL. It demonstrates practical skills in data cleaning, data transformation, exploratory analysis, and writing structured SQL queries.

---

## 📌 Project Overview

Real-world datasets often contain duplicate records, missing values, inconsistent formats, and other data-quality issues.

In this project, I worked with a layoffs dataset and used SQL to:

- Explore the raw dataset
- Identify data-quality issues
- Remove duplicate records
- Handle missing and inconsistent values
- Standardize data
- Transform columns where necessary
- Perform exploratory data analysis
- Extract useful insights using SQL queries

## 🧹 Data Cleaning

The ```01_Data_Cleaning.sql ``` file contains SQL queries used to prepare the dataset for analysis.

The cleaning process includes tasks such as:

* Creating a staging table
* Inspecting the raw data
* Identifying duplicate records
* Removing duplicate records
* Standardizing inconsistent values
* Handling NULL and blank values
* Converting data into suitable formats
* Removing unnecessary records or columns where appropriate

## 🔎 Exploratory Data Analysis

The ```02_Exploratory_Analysis.sql ``` file contains SQL queries for exploring the cleaned dataset.

The analysis focuses on questions such as:

* Which companies recorded the highest layoffs?
* Which industries were affected by layoffs?
* Which countries had the highest number of layoffs?
* How did layoffs change over time?
* Which companies experienced large-scale layoffs?
* What patterns can be observed in the layoffs data?
